## 1. 프로젝트 개요
- **이음이** = 서초 어르신용 **음성 복지 안내 키오스크** (라이브 서비스)
- 레포: `github.com/jinwoolim-art/ieumi-kiosk`, 작업 브랜치 **`Update-Server`**
- 서버: **이 Windows PC** `D:\GitHub\ieumi-kiosk`, `localhost:8791`
- 공개 주소: **`ieumi.illkkun.cloud`** (cloudflared 고정 터널, 서비스로 자동시작)
- DB: Neon Postgres (공유, 즉시 반영). 서비스 **60개** 학습됨
- 모델: 대화=**Claude Sonnet-5**, QA평가=**Haiku**. 음성=**네이버 클로바**(STT/TTS)
- 협업: 알리레자(백엔드 개발자, **메시지는 한글로만**)

## 5. 운영 명령 (이 Windows에서)
```
cd D:\GitHub\ieumi-kiosk\ieumi-server
git pull                         # 최신 코드
# 서버 재시작: 서버 창 닫고 tools\start-kiosk.bat (코드 변경 시)
node db\qa-eval.js               # QA 전체 평가 (~$4.5, 결과 CSV)
node db\audit.js                 # 학습 상태 감사 (크레딧 0)
node db\sync-sources.js s30 --force   # 특정 서비스 재학습
node db\set-voice.js             # 목소리 vian 설정
```

## 6. 꼭 지킬 원칙
- **라이브 프로덕션** — 작은 단위·additive·롤백 가능하게. 서버/DB 함부로 X
- **비용**: 이음이 API(종량, 대화·학습·QA테스트)와 Claude Code(정액, 내 작업)는 별개 지갑.
  QA 재테스트는 가능하면 **구멍만** 돌려 비용 절감
- **알리레자 메시지는 한글로만** (영어 2중번역 손실)
- **.env 시크릿**(KEY/SECRET/PASSWORD/TOKEN)은 값 출력 시 마스킹
- **git 커밋 끝에**: `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`
- 변경은 **Update-Server 브랜치**에 commit + push
