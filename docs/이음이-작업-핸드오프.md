## 5. 운영 명령 (이 Windows에서)
```
cd D:\GitHub\ieumi-kiosk\ieumi-server
git pull                         # 최신 코드
# 서버 재시작: 서버 창 닫고 tools\start-kiosk.bat (코드 변경 시)
node db\qa-eval.js               # QA 전체 평가 (~$4.5, 결과 CSV)
node db\audit.js                 # 학습 상태 감사 (크레딧 0)
node db\sync-sources.js s30 --force   # 특정 서비스 재학습
node db\set-voice.js             # 목소리 vian 설정
```
